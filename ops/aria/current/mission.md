# Aria Mission

Aria should feel:

- stable
- fast enough to feel good
- feature-complete and testable
- intelligent, warm, and engaging

Current product order remains:

1. make Aria stable
2. make her fast enough to feel good
3. make her features complete and testable
4. only then invest hard in fuller animation

This repo is optimized for the Android launch-critical path first, especially the primary device `70578ba3` / `IN2017`.
