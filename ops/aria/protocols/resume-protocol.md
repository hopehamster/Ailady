# Resume Protocol

Use this whenever a session resumes after a gap or when chat history is missing.

## Required Read Order

1. `PROJECT_MEMORY_LEDGER.md`
2. `ops/aria/README.md`
3. `ops/aria/current/mission.md`
4. `ops/aria/current/priorities.md`
5. `ops/aria/current/active-work.md`
6. `ops/aria/current/known-regressions.md`
7. `ops/aria/current/architecture-state.md`
8. `ops/aria/current/tooling-state.md`
9. newest `ops/aria/log/*`

## Resume Outcome

Before meaningful work begins, the agent should be able to state:

- what Aria is currently trying to achieve
- what was just completed
- what must happen next
- what current risks/regressions exist

## Memory Rule

If local memory is missing or contradictory, repair the local memory before product work continues.
