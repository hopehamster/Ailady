# Genies Unity SDK - GitHub Installation Guide

## Found the SDK on GitHub! 🎉

The Genies Unity SDK is available on GitHub:
- **Repository**: https://github.com/geniesinc/Singular-Unity-SDK-Genies
- **License**: MIT (free to use)
- **Last Updated**: Jan 5, 2026 (very recent!)

---

## Installation Method 1: Unity Package Manager (Recommended)

### Step 1: Get GitHub URL
The repository URL is:
```
https://github.com/geniesinc/Singular-Unity-SDK-Genies.git
```

### Step 2: Install in Unity

1. **Open Unity Editor** (2022.3.62f2)
2. **Open your project** (or create new one)
3. **Go to**: `Window > Package Manager`
4. **Click the "+" button** (top left)
5. **Select**: "Add package from git URL"
6. **Enter URL**:
   ```
   https://github.com/geniesinc/Singular-Unity-SDK-Genies.git
   ```
7. **Click "Add"**
8. **Wait for installation** (Unity will download and install)

## Installation Method 2: Clone Repository

### Step 1: Clone to Local

```bash
cd tools/girlai2/unity
git clone https://github.com/geniesinc/Singular-Unity-SDK-Genies.git
```

### Step 2: Import into Unity

1. **Open Unity Editor**
2. **Assets > Import Package > Custom Package...**
3. **Navigate to cloned folder**
4. **Select the package file** (if available)
5. **Or drag folder into Unity Assets**

---

## Installation Method 3: Download ZIP

### Step 1: Download

1. Go to: https://github.com/geniesinc/Singular-Unity-SDK-Genies
2. Click "Code" → "Download ZIP"
3. Extract ZIP file

### Step 2: Import

1. **Open Unity Editor**
2. **Assets > Import Package > Custom Package...**
3. **Or drag extracted folder** into Unity Assets window

---

## Recommended: Use Package Manager (Method 1)

**Why?**
- ✅ Automatic updates
- ✅ Clean installation
- ✅ Easy to remove/update
- ✅ No manual file management

## Troubleshooting

### Issue: "Package not found"
**Fix**: 
- Check internet connection
- Verify URL is correct
- Try cloning manually instead

### Issue: "Authentication required"
**Fix**:
- Repository is public, shouldn't need auth
- If private, contact Genies for access

### Issue: "Version incompatible"
**Fix**:
- Make sure Unity 2022.3.62f2 is installed
- Check repository for Unity version requirements
