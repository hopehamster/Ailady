# Product Manager Role Guide

Responsibilities and workflows for the Product Manager role.

## Responsibilities

### Feature Planning
- Define features
- Prioritize features
- Plan releases
- Manage backlog

### User Stories
- Write user stories
- Define acceptance criteria
- Estimate effort
- Track progress

### Release Planning
- Plan release scope
- Set release dates
- Coordinate releases
- Communicate changes

### User Feedback
- Collect feedback
- Analyze feedback
- Prioritize improvements
- Plan updates

## Key Areas of Focus

### Product Vision
- Understand product goals
- Align features with vision
- Prioritize value
- Measure success

### User Needs
- Understand users
- Identify pain points
- Plan solutions
- Validate solutions

### Release Management
- Plan releases
- Coordinate teams
- Communicate changes
- Monitor adoption

## Workflows

### Feature Planning
1. Understand user need
2. Define feature scope
3. Write user story
4. Define acceptance criteria
5. Estimate effort
6. Prioritize feature

### Release Planning
1. Review backlog
2. Select features
3. Set release date
4. Assign work
5. Track progress
6. Adjust plan

### User Feedback
1. Collect feedback
2. Analyze feedback
3. Identify patterns
4. Prioritize improvements
5. Plan updates
6. Communicate changes

## User Story Format

### Template
```
As a [user type]
I want [feature]
So that [benefit]
```

### Acceptance Criteria
- Clear and testable
- Complete feature definition
- Measurable outcomes

## Best Practices

### Feature Definition
- Clear requirements
- User-focused

### Prioritization

### Communication

- User-focused messaging
