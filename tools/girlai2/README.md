# GirlAI2 - AI Girlfriend App

A premium AI girlfriend app built with Flutter, Firebase, and Unity integration.

## Features

- **OTP-only Authentication**: Phone number-based login with SMS verification
- **Multi-LLM Orchestration**: Uses Claude Opus, GPT-5.2, and Gemini 3 Pro for different conversation types
- **3D Avatar Integration**: Unity-powered avatars with Ready Player Me
- **Relationship Simulation**: Trust, intimacy, empathy, and novelty metrics
- **Gamification**: XP, Bond Points, milestones, and unlockable rewards
- **Scheduled Dates**: Calendar system with missed date tracking
- **Premium Subscription**: In-app purchase support

## Setup Instructions

### 1. Install Dependencies

```bash
cd tools/girlai2
flutter pub get
```

### 2. Firebase Configuration

1. Make sure you're logged into Firebase:
```bash
firebase login
```

2. Configure Firebase for your Flutter app:
```bash
flutterfire configure --project=girlai2
```

3. Set up Cloud Functions:
```bash
cd functions
npm install
```

4. Set environment variables for LLM APIs:
```bash
firebase functions:config:set openai.api_key="YOUR_OPENAI_KEY"
firebase functions:config:set anthropic.api_key="YOUR_ANTHROPIC_KEY"
firebase functions:config:set google.api_key="YOUR_GOOGLE_KEY"
```

5. Deploy Firestore rules and indexes:
```bash
firebase deploy --only firestore:rules,firestore:indexes
```

6. Deploy Cloud Functions:
```bash
cd functions
npm run deploy
```

### 3. iOS Configuration

1. Add `GoogleService-Info.plist` to `ios/Runner/` (generated by flutterfire configure)
2. Ensure phone authentication is enabled in Firebase Console
3. Configure your iOS app bundle ID in Firebase Console

### 4. Unity Integration (Optional - for later)

Unity integration is set up with placeholder services. When ready:
1. Create Unity project with Ready Player Me SDK
2. Export Unity module
3. Integrate with Flutter using `flutter_unity_widget`
4. Update `lib/features/avatar/widgets/avatar_view.dart` with actual Unity widget

## Architecture

- **Frontend**: Flutter (iOS first)
- **Backend**: Firebase (Auth, Firestore, Cloud Functions, Storage)
- **AI**: Langchain orchestration with multiple LLMs
- **Memory**: Firestore for permanent memory, session memory in Firestore
- **3D Avatars**: Unity + Ready Player Me (placeholder structure ready)
