# Aria Security — Real-Tool Attack Volley (2026-06-22)

> A thorough offensive pass against the **running** Aria stack with actual pentest tools, every
> finding independently calibrated by a 3-skeptic adversarial pass (nothing self-graded).
> Authorized white-box test of the owner's own pre-launch product; local-only attack range.
> Follow-up to the 2026-06-22 audit + remediation (8+2 findings already fixed). **Report-first:
> no code changes pending owner approval** (the standing-gate test infra is the one pre-authorized exception).

## Bottom line (the "are we sure?" answer)
Against **routine attacks any company is expected to handle, the shipping defenses HOLD.** JWT
crypto, injection defenses, the SQL layer, race handling, and the LLM safety chain all withstood
real-tool attack. **No critical and no high findings.** The single non-trivial item is the
**CDN-loaded avatar engine (MEDIUM)** — already a documented pre-launch TODO. Everything else is
**LOW/INFO** defense-in-depth hardening, and one candidate was dismissed as a non-issue. A competent
attacker does not walk through this stack today.

## Method
- **Targets (local):** primary worker `:8787`, web `:5173`, the DIY phone-OTP auth spike stood up live on `:8788` (D1 migrated, a real ES256 token pair minted via the live OTP flow).
- **Tools:** nuclei v3.9.0 (6,620 templates), sqlmap, ffuf, retire.js, npm audit, PyJWT (JWT forgery), custom LLM red-team + concurrency harnesses, the 762-skill cyber playbooks.
- **Calibration:** every candidate finding judged by **3 independent skeptics** against the real code (workflow `wf_cdfc9881-b52`, 24 agents) → severities recalibrated, one candidate dismissed.

## Findings (calibrated severities; 3/3 skeptic consensus unless noted)

| # | Finding | Sev (calibrated) | Proof | Fix |
|---|---|---|---|---|
| **F3** | **Live avatar engine loads three.js + TalkingHead from jsDelivr CDN at runtime with NO Subresource-Integrity and NO CSP on the web HTML.** A CDN/network compromise = RCE in an intimate-companion app. | **MEDIUM** (was HIGH; pinned SHA/version mitigates, but still a real pre-launch RCE surface) | `apps/web/index.html` importmap `three@0.180.0`; `apps/web/src/avatar/TalkingHeadDriver.ts:14` dynamic import of a commit-SHA module; `integrity=` count 0; CSP count 0 | Self-host three + TalkingHead from our origin/R2, drop the importmap, add a strict `script-src` CSP (+ SRI). Already a `TODO(prod)` in the code. |
| **F1** | No rate limit on `/v1/auth/refresh` (the one unthrottled auth endpoint). | **LOW** (was MED — the "indefinite access" is a token-lifetime *design* property, not this gap; reuse-detection + 30-day TTL already bound the blast radius) | 8/8 chained rotations, zero 429; `handleRefresh` has no `RateLimit.limit()` | Add a per-IP + per-uid `RateLimit` binding on refresh (defense-in-depth / DoS hygiene). |
| **F4** | The **primary worker** has zero rate-limiting on every endpoint; `/api/chat` has no message length cap → token-flood cost-DoS on real DeepSeek. | **LOW** (dev-only today — gated behind `devGate`; becomes real once Phase-3 auth opens it) | code: no `.limit()`, `index.ts:189` only rejects empty | Add per-uid/IP rate limits + a chat length cap when real auth lands (Phase 3). |
| **F2** | `/v1/admin/keys/rotate` admin-token check is a non-constant-time `!==` with no rate limit / lockout. | **LOW** (was MED — `ADMIN_TOKEN` is a strong secret + fails closed when unset; brute impractical) | 15 wrong tokens → all 403 in 0.08s | Constant-time compare + a rate limit on the admin route. |
| **F5** | The **spike worker (:8788)** and the **web HTML (:5173)** set no security headers (CSP/nosniff/referrer/frame). The primary worker already sets them. | **LOW** | nuclei `http-missing-security-headers` fired on :8788 + :5173, **not** :8787 | Add the same `SECURITY_HEADERS` block to the spike + a web CSP (folds into F3). |
| **F6** | The memory write-gate **stores** instruction-shaped content when framed as a user "preference/condition." | **INFO** (the model + REFERENCE-DATA fence prevent obedience — 0/7; latent risk only if a future weaker model obeys) | both poison variants persisted to D1 `coreFacts`; 0/7 obeyed | Optional: tighten the write-gate to also drop preference-framed imperatives; keep the fence. |
| **F8** | `uid = x-dev-uid` header → any dev-secret holder can act as any uid (cross-tenant). | **INFO** (documented **dev-only** auth model; prod fail-closes `ENV!=dev → 401`) | `index.ts:187` | Closes when phone-OTP auth replaces the dev gate (Phase 3). |

**Dismissed (for trust):** *F7 — `/healthz` env name + CORS `*`* was a candidate but the calibration **rejected it 0/3** as a non-issue (env name is trivial; `*` CORS on a header-credentialed, no-cookie API is not exploitable). Not a finding.
